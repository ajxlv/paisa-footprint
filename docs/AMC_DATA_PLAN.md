# AMC portfolio data plan

SEBI requires every mutual fund house (AMC) to publish each scheme's full portfolio at least
monthly. Those files are the "holdings" input to fund rankings. **No real AMC file has been
downloaded or committed.** The pipeline is built and tested on a synthetic workbook
(`tests/fixtures/synthetic/amc_portfolio_synthetic.xlsx`, generated by `make_amc_fixture.py`).

## Which AMCs to start with (unverified suggestions)

| AMC | Why start here | Where the files usually are (verify) |
|---|---|---|
| SBI Mutual Fund | Largest Indian AMC; many equity schemes | The AMC website's "Portfolio" or "Downloads" / statutory disclosures section, as monthly Excel files |
| HDFC Mutual Fund | Large, long-running equity range | The AMC website's statutory disclosures, as monthly portfolio Excel |
| Parag Parikh Mutual Fund | Few schemes, which makes it simple to check by hand | The AMC website's "Downloads" / portfolio disclosures |

These are suggestions from the design doc (open question 3), **not verified**. Website layouts
change. Look for the latest **monthly portfolio** file for **equity** schemes, in `.xlsx`.
If a site only offers `.xls` (old Excel), open it in Excel and "Save as" `.xlsx`.

## Where to put them

```
data/raw/amc/<amc>/<YYYY-MM>.xlsx
```

For example: `data/raw/amc/sbi-mf/2026-03.xlsx`, `data/raw/amc/hdfc-mf/2026-03.xlsx`.

- `<amc>` becomes the AMC name in the results; keep it short and lowercase.
- `<YYYY-MM>` is the portfolio month. It is used as the "as on" date only if the sheet itself
  doesn't state one, and a note records that it was used.
- `data/` is git-ignored: real files stay on your laptop.

## Run it

```powershell
pf ingest-funds --input data/raw/amc --out data/snapshots/2026-10/funds.parquet
pf rank-funds --snapshot data/snapshots/2026-10 --evic-real data/evic/evic_2026-03.csv
```

`ingest-funds` prints every scheme it found plus every V8 warning. `rank-funds` prints the table
and writes `fund_rankings.json` next to the snapshot, which the app's Funds page reads.

## What the generic adapter handles

- A header row is found by scanning for "ISIN" plus a market-value or "% to NAV" column, so the
  table can start on any row. A two-row merged header (e.g. "Market Value" over "(Rs. in Lakhs)")
  is combined.
- Values in ₹ lakh, crore or thousands are converted to rupees from the header text. If the unit
  isn't stated, rupees are assumed and a note says so.
- One scheme per sheet **or** several schemes stacked on one sheet.
- "Sub Total"/"Total" rows are skipped, and "Grand Total" ends a scheme.
- Cash, TREPS and net-receivable lines without an ISIN are kept as non-equity.

If an AMC's file still parses wrongly, paste the first 15 rows of one sheet into the thread and a
dedicated adapter can be added behind the same `AmcAdapter.parse(path)` interface.

## Checks (rule V8 and friends)

| Rule | Check | Severity |
|---|---|---|
| V8 | % to NAV over all lines (equity, debt, cash) is outside 95–105% | warning |
| V8-isin | An ISIN that is present but not in INE… format | warning |
| V8-dup | The same ISIN appears twice in a scheme: the lines are summed | warning |
| V7 | An equity ISIN that matches no BRSR company: listed as uncovered | — |

A fund whose covered equity value is under **50%** shows "insufficient coverage" and is not
ranked.
